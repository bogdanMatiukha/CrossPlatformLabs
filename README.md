# Інформаційна система видачі та повернення університетського майна

Клієнт-серверний застосунок для обліку університетського майна, обробки заявок на видачу та контролю повернення.

## Технології

- **Java 21**
- **JavaFX** для графічного інтерфейсу
- **Apache Tomcat 9.x** для серверної частини
- **Java Servlets** для обробки HTTP-запитів
- **MySQL** для зберігання даних
- **JDBC та DAO** для роботи з базою даних
- **Maven** для складання проєкту
- **JUnit 5** для тестування

## Основні можливості

- Перегляд, додавання, редагування та видалення користувачів, майна й заявок.
- Перегляд журналу передач майна.
- Пошук і фільтрація записів у таблицях.
- Імпорт інвентарю з CSV-файлу.
- Розрахунок інтегрального показника пріоритетності заявки.
- Контроль життєвого циклу заявки та автоматичне оновлення статусу майна.
- Відображення стану фонового імпорту.

## Структура системи

Система складається з двох частин:

- **`server`**: серверний застосунок, який обробляє HTTP-запити, виконує бізнес-логіку та працює з MySQL.
- **`client`**: JavaFX-застосунок, який надає користувачу графічний інтерфейс і взаємодіє із сервером через HTTP та JSON.

Основні сутності:

| Сутність | Призначення |
|---|---|
| `User` | Користувач системи |
| `PropertyItem` | Одиниця інвентарного майна |
| `IssueRequest` | Заявка на видачу майна |
| `Transfer` | Запис про передачу та повернення майна |

## Вимоги

Перед запуском переконайтеся, що встановлено:

- JDK 21
- Maven
- MySQL
- Apache Tomcat 9.x

Також потрібно налаштувати доступ до MySQL у класі `DBUtil` серверної частини.

## Налаштування бази даних

1. Запустіть MySQL.
2. Створіть базу даних `university_property_db` і таблиці відповідно до SQL-скрипту проєкту.
3. Перевірте параметри підключення в `DBUtil`.

Приклад JDBC URL:

```text
jdbc:mysql://localhost:3306/university_property_db?useUnicode=true&characterEncoding=UTF-8&serverTimezone=UTC
```

Якщо для MySQL встановлено пароль або інше ім'я користувача, оновіть відповідні значення в конфігурації.

## Запуск серверної частини

Відкрийте термінал у каталозі `server` і виконайте:

```bash
mvn clean package
```

Після успішного складання скопіюйте створений WAR-файл із `server/target` до каталогу `webapps` Tomcat 9.x. Запустіть Tomcat за допомогою `bin/startup.bat`.

Якщо назва WAR-файлу відрізняється, використовуйте фактичну назву, створену Maven. Переконайтеся, що контекст застосунку та URL у клієнті відповідають конфігурації Tomcat.

Для перевірки можна відкрити endpoint користувачів:

```text
http://localhost:8080/university_property/users
```

За умови правильного розгортання сервер має повернути JSON-відповідь.

## Запуск JavaFX-клієнта

Переконайтеся, що MySQL і Tomcat запущені. У новому терміналі перейдіть до каталогу `client`:

```bash
cd client
mvn javafx:run
```

Відкриється головне вікно системи з вкладками:

- Заявки на видачу
- Користувачі
- Інвентар майна
- Журнал передач

Якщо сервер розміщено за іншою адресою або портом, оновіть базову URL-адресу в налаштуваннях HTTP-клієнта.

## Життєвий цикл заявки

Передбачено такі основні статуси:

1. `CREATED` — заявку створено.
2. `APPROVED` — заявку погоджено; створюється запис журналу передач без дат.
3. `PUBLISHED` — майно видано, записується дата передачі, а статус майна змінюється на `UNAVAILABLE`.
4. `RETURNED` — майно повернуто, записується дата повернення, а статус майна змінюється на `AVAILABLE`.

Дозволені переходи статусів контролюються серверною бізнес-логікою.

## Інтегральний показник

Пріоритетність заявки оцінюється за трьома факторами:

- `F1` — терміновість робіт;
- `F2` — критичність майна;
- `F3` — дефіцит доступних одиниць.

Кожен фактор має значення від 0 до 100. Формула розрахунку:

```text
I = 0.40 * F1 + 0.35 * F2 + 0.25 * F3
```

## Імпорт CSV

Клієнт підтримує імпорт інвентарю з CSV-файлу. Очікуються чотири поля:

```csv
inventory_number,name,category,status_item
INV-101,Ноутбук HP ProBook,Комп'ютерна техніка,AVAILABLE
INV-102,Монітор Samsung,Комп'ютерна техніка,AVAILABLE
```

Файл має бути збережений у кодуванні UTF-8. Для статусу майна потрібно використовувати значення, підтримувані переліком `ItemState` у проєкті, наприклад `AVAILABLE` або `UNAVAILABLE`.

## Тестування

Тести клієнт-серверної взаємодії написані з використанням JUnit 5. Для їх запуску перейдіть до каталогу `client` і виконайте:

```bash
mvn test
```

Оскільки тести звертаються до сервера через HTTP, для їх успішного виконання мають працювати Tomcat і MySQL, а тестові дані мають відповідати обмеженням бази даних.

## Примітки

- JavaFX-клієнт не підключається до MySQL напряму, а працює через сервер.
- Назва WAR-файлу та контекстний шлях Tomcat залежать від конфігурації Maven і розгортання.
- Перед запуском на іншому комп'ютері перевірте URL сервера, параметри MySQL і наявність необхідних таблиць.
